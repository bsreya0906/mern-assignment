# Employee Management System

A modern Employee Management System built with **React, Vite, Tailwind CSS, Axios, and MockAPI**. The application allows users to manage employee records with complete CRUD (Create, Read, Update, Delete) functionality through a clean and responsive interface.

## 🚀 Live Demo

🌐 https://youremployee.netlify.app/

## 📂 GitHub Repository

https://github.com/bsreya0906/mern-assignment

---

## ✨ Features

- Add new employees
- View all employees
- Update employee details
- Delete employees
- Search employees instantly
- Responsive UI
- Dashboard showing total employees
- MockAPI integration
- Clean and modern design

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/bsreya0906/mern-assignment.git
```

Go to the project folder

```bash
cd mern-assignment/frontend
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
